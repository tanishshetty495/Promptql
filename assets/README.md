# Assets Directory

This directory contains static assets for the PromptQL project.

## Demo GIF

Place a demonstration GIF named `demo.gif` in this directory to showcase the application in action.

The GIF should demonstrate:
- Natural language querying
- Query history sidebar
- Dark/light theme toggle
- Export functionality (CSV, JSON, Excel)
- Success celebrations
- Query time celebrations
- Connection status indicators

Refer to the main README.md for how this asset is used in the documentation.
